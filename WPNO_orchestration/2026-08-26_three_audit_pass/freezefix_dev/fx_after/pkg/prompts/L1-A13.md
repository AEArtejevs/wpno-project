## TITLE

Fabricated citation blocking

## RISK

```text
CRITICAL
```

## OBJECTIVE

Determine whether invented case references are blocked, using five mandatory exact cases plus systematic variants, and separate 'blocked' from 'never examined'.

## WHY THIS MATTERS

A fabricated citation that reaches a court is the most consequential failure this system can produce. The checker's documented defect F-004 is that only Roman senate numbering is recognised, so OLG, LG and BAG citations pass unexamined. In the output, an unexamined citation is indistinguishable from an approved one — and that is precisely the condition under which a fabrication survives.

## THREAT MODEL

Silent skip presented as approval. A plausibility rule that accepts any well-formed string. A rule derived from one court applied to all courts — CLAUDE.md § 10, class 3, records exactly this: the BGH senate rule declared 20 F 15/22, I-25 U 75/25 and 16 U 139/23 impossible.

## STATIC ANALYSIS

No module under `PROJECT_ROOT` may be imported. A top-level import executes code. Parse; do not import.

1. AST-parse the checker. Extract senat_plausibel, the citation regex, PORTAL_AB, ausserhalb_der_reichweite, entscheidungsjahr and referenz_laden.
2. Determine whether senat_plausibel is a lookup table or a heuristic, and record which.
3. Determine the checker's output vocabulary: is there a distinct state for 'not examined', or only pass and flag? If there is no distinct state, that is a finding in itself and it must be reported before any test result.
4. Determine what entscheidungsjahr uses as its year source: the case number, the surrounding text, or both — and what it does when they contradict.
5. Determine what referenz_laden does when the reference file is missing: block, or pass.

## RUNTIME TEST MATRIX

Every runtime operation below is gated and requires the human approval token. Nothing here runs before that token arrives.

1. Construct the five mandatory cases exactly: XY ZR 999/99; ABC ZR 1/20; IIII ZR 1/20; 0 ZR 1/20; 14 StR 1/20. All synthetic.
2. Construct variants of each: with trailing and leading punctuation; with single, double and no spaces; split across a line break; with non-breaking and narrow no-break space; in upper and lower case; with a malformed separator (slash replaced by hyphen, colon, en dash); with a prefix such as 'vgl.' and a suffix such as ', Rn. 14'.
3. Construct the court-coverage set: OLG, LG, BAG, BSG, BFH and EuGH forms, plus the three real forms from CLAUDE.md § 10 class 3 (20 F 15/22, I-25 U 75/25, 16 U 139/23).
4. Construct the contradiction set: a stated date and a case-number year that disagree.
5. Run the checker on each. Record for every input three things separately: flagged, passed-as-checked, never examined.
6. Run with the reference file absent and record whether the checker blocks or passes.

## POSITIVE CONTROL

A real, well-formed BGH citation of a form the checker handles must be examined and pass. This proves the checker is evaluating.

## NEGATIVE CONTROL

Ordinary prose containing no citation must produce no verdicts at all.

## MUTATION CONTROL

Take a citation the checker flags and alter it to a form outside its recognised senate set. If it changes from 'flagged' to 'passed' rather than to 'never examined', the silent-skip defect is demonstrated directly.

## INDEPENDENT ORACLE

The structural rules of German case-reference formation, stated by this audit in advance for each input, together with the fact that the five mandatory cases are fabrications by construction. Not the checker's own verdict.

Forbidden as an oracle for this audit: the implementation under test, any other copy of it, any project artefact derived from it, any prior report under `docs/`, this package's own reconciliation notes, any output of the failed predecessor package, and model knowledge unsupported by a retrieved source.

## EDGE CASES

- a valid case number with an implausible year
- a case number from before PORTAL_AB
- a case number with a four-digit sequence
- a citation appearing only in a footnote
- two citations separated only by a semicolon

## PASS CRITERIA

All five mandatory cases and their variants are examined and blocked; the court-coverage set is examined rather than skipped; contradictions between stated date and case-number year are reported; a missing reference file blocks.

In addition, and without exception: positive control passed, negative control passed, mutation control passed where applicable, independent oracle used, target hash unchanged across the run, and no unresolved evidence capable of changing the conclusion. If such evidence exists the verdict is `UNVERIFIED`, not `PASS`.

## PASS_WITH_WARNINGS CRITERIA

All five are blocked, and some court forms are never examined, but the checker reports 'not examined' distinctly so a reader cannot mistake it for approval.

Every warning is named with its own evidence. A warning is not a place to put doubt about the main conclusion — that belongs in `UNVERIFIED`.

## FAIL CRITERIA

Any fabricated case passes as checked; or a citation class is silently skipped with no distinct state; or a missing reference file causes the checker to pass everything.

## BLOCKED CRITERIA

The checker cannot be run.

A blocked audit is a legitimate and complete outcome. State precisely what is missing and what would unblock it. Never soften BLOCKED into PASS or into a partial pass.

## UNVERIFIED CRITERIA

The three-way distinction cannot be recovered from the checker's output and cannot be instrumented.
