## OBJECTIVE

Independently enumerate and classify all 43 citations in the real document, compute the BGH count without the production counter, compare, and record every disagreement.

## WHY THIS MATTERS

CLAUDE.md § 10, class 5, records a counter that searched only for BGH register signs, found three of ten references, and then reported that all references were supported. A counter reports what it can see, and the number it prints carries no indication of what it could not see. The only way to test a counter is to count independently.

## THREAT MODEL

Using the production counter as its own oracle. Counting hits rather than unique citations, or the reverse, and comparing incompatible quantities. Classifying by the same pattern the counter uses, which reproduces its blind spot exactly.

## STATIC ANALYSIS

No module under `PROJECT_ROOT` may be imported. A top-level import executes code. Parse; do not import.

1. AST-parse the counter. Determine exactly what it counts: unique citations, or occurrences. Determine how it classifies a citation as BGH.
2. Record the classification rule verbatim, because the independent classification must not reuse it.
3. Record known document facts as a hypothesis to be tested, not as truth: 43 unique citations, 82 hits, six in a high-risk band, one I ZR outlier, none before 2000.

## RUNTIME TEST MATRIX

Every runtime operation below is gated and requires the human approval token. Nothing here runs before that token arrives.

1. Locate the operator-supplied document in references/ (REF-06). Verify its SHA-256 against references/manifest.json. Record path, size and hash. If absent: BLOCKED. The document is client material.
2. Extract the document's text independently in the sandbox: unzip and parse word/document.xml with external entities and DTD disabled. Never open a word processor.
3. Enumerate every citation by an independent method: a citation grammar written for this audit from the structural rules of German case references, applied to the extracted text, with every candidate reviewed rather than accepted on the pattern alone.
4. Record unique citations and total occurrences as two separate numbers.
5. Classify each citation independently by issuing court, using the court designator, not the counter's rule.
6. Compute the independent BGH count.
7. Run the production counter on the same document. Record its output.
8. Compare unique-count, occurrence-count and BGH-count. Enumerate every individual disagreement with the citation text and both classifications.
9. Report the citation content in redacted form only: designator, court and year. No case content, no party names, no surrounding text.

## POSITIVE CONTROL

Seed a synthetic copy of the document with one additional unmistakable BGH citation. Both the independent method and the production counter must increase by one. This proves both methods respond.

## NEGATIVE CONTROL

Run both methods over a text with no citations. Both must report zero.

## MUTATION CONTROL

Remove one BGH citation from a synthetic copy. The independent count must fall by one. If it does not, the independent method is not independent enough to be an oracle.

## INDEPENDENT ORACLE
